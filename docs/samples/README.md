## パンフレット（巻き三つ折り）

### 判型

用紙 **A4横（297×210mm）両面1枚**／仕上がり **100×210mm（縦見）**。長形3号封筒（120×235mm）に入る定形サイズです。

### 面付け

- **1枚目＝外面** 左→右：内フラップ 97mm ｜ 裏表紙 100mm ｜ 表紙 100mm
- **2枚目＝内面** 左→右：内側左 100mm ｜ 内側中央 100mm ｜ 内フラップ裏 97mm

巻き三つ折りは内側に巻き込まれるパネルが紙の厚みの分だけ余るため、そのパネルだけ 97mm（3mm 短く）にしています。

### 折り方

外面を上にして、**左端のパネルを内側へ折り込み、続けて同じ向きにもう一度折る**と、右端が表紙になります。

### 印刷設定

A4・**横**・等倍（100%）・両面（長辺とじ）。画面に見えている破線の折りガイドは印刷されません。詳しくは末尾の「PDF保存・印刷の設定」を参照。

印刷プレビューが **2ページ**（外面・内面）になっていることを確認してください。4ページになっている場合は各面が2枚に割れています。

### デザインの決めごと

紙面はサイトの UI をそのまま持ち込む方針で作っています。参照元は `app/globals.css`・`tailwind.config.ts`・`components/SectionHeading.tsx`・`components/ProductCard.tsx` です。

- **地は白**。パネルごとの地色は `#f9fafb`（サイトのフッターと同じ）を内フラップにだけ使い、折り線をまたぐ色面は置いていません。
- **すべての面が角丸 2.1mm の矩形**です。サイトの `--radius-DEFAULT: 8px` を mm に換算した値で、写真もカードもバッジもこの値に揃えています。円形マスクやアーチ型は使っていません。
- **区切りは `#e5e7eb` の実線**（0.25mm）。サイトの `divide-[#e5e7eb]` と同じ色です。点線は使っていません。
- **見出しは左寄せ＋直下に 12mm のコーラルのアンダーバー**。`SectionHeading.tsx` の `h-0.5 w-12 bg-accent1` と同じ作法です。
- **バッジは角丸矩形**。NEW はマスタード `#ffc94d`、順位はコーラル `#ff7a8a` で、`ProductCard.tsx` のバッジと同一の配色です。
- 色はサイトのトークンと同一（`#ff7a8a` / `#ffc94d` / `#333333` / `#6b7280` / `#9ca3af` / `#e5e7eb` / `#f9fafb`）。小さな級数で沈まないよう、文字色にはコーラルを一段濃くした `--coral-ink: #d84a5c` を使っています。
- 商品写真は白背景の平置き・モデル写真をトリミングせずそのまま 1:1 で置いています。スタイリング事例だけ 3:4 の縦組みです。

#### 内面を横断する身長スケール

内面の中段には、**50cm から 160cm までの身長スケールが3パネルを一直線に横断します**。`app/size-guide/page.tsx` の早見表を、折って開く動作そのものに載せた仕掛けです。

**これはサイズ「早見表」であって在庫一覧ではありません。** 現在の取扱いは 60〜120cm（シューズ14〜17cm、帽子・小物はフリーサイズ）なので、表紙の数字は `60-120 SIZE IN STOCK`、右パネルの注記にも取扱い範囲を明記してあります。取扱いサイズが広がったら、この2か所を更新してください。

- 左パネル＝ **BABY 50〜80cm**、中央パネル＝ **KIDS 90〜130cm**、右パネル＝ **JUNIOR 140〜160cm**。目盛りの実寸位置がそのまま各パネルに収まるよう配置しています。
- **折り線（x=100mm / x=200mm）をまたぐのは水平線だけ**です。目盛り・数字・色面はいずれも折り線から 10mm 以上離してあり、折りズレが出ても線の連続性しか影響を受けません。
- スケールは `2.4818mm/cm`（x=12mm が 50cm、x=285mm が 160cm）で等間隔に置いています。目盛りの座標を動かす場合は `.deco` の SVG（viewBox が `0 0 297 210`＝mm 実寸）と、`.sz-head` / `.sz-group` / `.sz-gap` の高さ配分の両方を合わせてください。`sz-gap` は絶対位置 102〜118mm にあたり、SVG のスケールはこの帯の中に描かれています。

### QRコード

`qr-mimora.svg`（`https://qianheb023com.com/`）を裏表紙と内面CTAの2か所に配置しています。生成は次のコマンドです。

```
npm i -D qrcode                                                            # 初回のみ
node scripts/make-qr.mjs "https://qianheb023com.com/" docs/samples/qr-mimora.svg
```

印刷用として次を固定しています。

- **ベクター（SVG）**。ラスタと違い倍率を上げても輪郭が潰れません
- **誤り訂正レベル Q（25%）**。折り目・かすれに強い
- **クワイエットゾーン 4モジュール**を viewBox に含めているので、枠や白地を敷く必要はありません
- **モジュールは #000000**。CMYK変換でスミ1色になり、版ズレでエッジがぼけません
- **符号化はURLを英大文字化**。URLのスキームとホストは大文字小文字を区別しないため遷移先は同じで、英数字モードに収まるので 25×25 モジュールのまま誤り訂正を Q に上げられます（小文字のままだとバイトモードで29×29に増えます）
- 配置は **22mm角**。1モジュール 0.67mm（33モジュール換算）で、スマートフォンでの読み取りに余裕があります

**等倍（100%）で試し刷りして、実機で読み取り確認をしてください。** 縮小コピーや用紙の光沢で読めなくなることがあります。

### 差し替えが必要な箇所

- **電話番号を載せていません。** `app/company/page.tsx` でも電話の行はコメントアウトされたままです。番号が決まったら、内フラップ「お問い合わせ」欄に追記してください。
- **サイト側のカテゴリ表記が実データとずれています。** `lib/categories.ts` は「ベビー服（50〜70cm）」ですが、`/category/baby` の商品が持つサイズは 60・70・80cm です。紙面は実データに合わせて「ベビー服（60〜80cm）」と表記しました。サイト側のラベルも直すことをおすすめします。
- 商品名「コンパクトヤミービブ NNB22512」は、紙面では品番を省いて「コンパクトヤミービブ」と表記しています。

## 事業計画書

A4縦・**5ページ**（表紙＋本文4ページ）。`@page { size: A4 portrait; margin: 0 }` と `print-color-adjust: exact` を指定してあるので、等倍・背景色ありでPDF化されます。

| ページ | 内容 |
|---|---|
| 表紙 | ― |
| 1 / 4 | 1. エグゼクティブサマリー ／ 2. 会社・事業概要 |
| 2 / 4 | 3. 市場環境・ターゲット顧客 ／ 4. 商品・サービス構成 |
| 3 / 4 | 5. 販売・集客戦略 ／ 6. 収支計画 |
| 4 / 4 | 7. 組織・運営体制とリスク ／ 8. 今後3年のロードマップ ／ 9. 資金使途 |

### ページが増えてしまったときは

**印刷プレビューのページ数が5より多いときは、どれかのページの中身が用紙からあふれています。** 節を足したり本文を長くしたときに起きます。あふれたページは2枚に割れるので、ページ数の増分がそのまま「あふれたページの数」です。

対処は次のどちらかです。

- 本文を削る（`.lead` の段落、テーブルの説明列がいちばん効きます）
- 節をページ間で移す（`<div class="foot">…</div></section>` と `<section class="page">` の組を、切りたい節の直前へ動かす）

なお `@media print` で `.page { height: 296.6mm }` と用紙より 0.4mm 低くしてあります。ぴったり 297mm にすると丸め誤差でわずかにはみ出した分が次の用紙へこぼれ、**中身が収まっていても1ページが2枚に割れます**。この値は下げないでください（パンフレットの `.face` も同じ理由で 209.6mm にしてあります）。

パンフレットと同じ視覚言語（白地・角丸2.1mmの矩形・`#e5e7eb` の罫・番号バッジ・12mmのアンダーバー）で組んでいます。全ページの左端 3mm にコーラル→マスタードのブランドバーが通ります。

### 収支計画の前提

売上は「受注件数 × 客単価」で積み上げています。平均単価が約¥1,800と低いため、**1回の注文で平均3.5点・客単価¥6,500**を置き、そこから件数を逆算しています。

| | 1年目 | 2年目 |
|---|---|---|
| 受注件数 | 約3,230件 | 約5,690件 |
| 売上高 | 2,100万円 | 3,700万円 |
| 原価率 | 55% | 52% |
| 営業利益 | 125万円 | 526万円 |

数字を変えるときは、`6. 収支計画` のKPIタイル（客単価・点数・件数）と表の売上高が連動していること、および `9. 資金使途` の広告宣伝費（売上比 約9.5%）が売上高と整合していることに注意してください。

`9. 資金使途` は資本金900万円の配分です（仕入400／広告200／システム120／撮影80／資材60／運転資金40）。

### 計画書に明記してある前提

- 現在の取扱いは **branshes 1ブランド・169アイテム**です。「マルチブランド型セレクトストア」は到達点であり、2年目までに3〜5社へ広げることを Phase 2 の最優先事項として本文に明記しています（`2. 会社・事業概要` の注記と `7. リスク`）。

## PDF保存・印刷の設定（両ファイル共通）

Chromeの印刷ダイアログで次のようにしてください。

| 項目 | 設定 | 理由 |
|---|---|---|
| 送信先 | PDFに保存 ／ プリンター | |
| 用紙サイズ | A4 | |
| 倍率 | **既定（100%）**。「用紙に合わせる」は使わない | 使うと紙面が縮小され、寸法設計と折り位置がずれます |
| 余白 | **既定** または なし | HTML側で `@page { margin: 0 }` を指定済み。ダイアログで「標準」等を選ぶとCSSの指定が上書きされます |
| ヘッダーとフッター | **チェックを外す** | 日付・タイトル・ファイルパス・ページ番号が紙面に載ってしまいます。**これはCSSから制御できません** |
| 背景のグラフィック | ONでもOFFでもよい | `print-color-adjust: exact` を指定してあるため、OFFでも背景色は出ます |

補足：

- `@page { margin: 0 }` は用紙の端まで使う指定です。家庭用・オフィス用プリンターは端の数mmが印刷できないため、地色が四辺でわずかに切れて白フチが残ります。フチなしにしたい場合は印刷所で塗り足し（3mm）付きの入稿データを作る必要があります
- コマンドラインからPDF化する場合（ヘッダー／フッターなしで確実に出力できます）:

```
chrome --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=out.pdf docs/samples/business-plan-sample.html
```

`docs/samples/` 内の HTML をブラウザで開いてください。画像は `public/images/` を相対パスで参照しています。

## 未確認の項目

紙面の寸法（面付け・折り位置・各段の高さ配分・スケールの折り線クリアランス）は計算で詰めてありますが、**実際のレンダリング結果は未確認です**。作成環境に日本語フォントが入っておらず、ヘッドレスブラウザでのPDF化も完了しなかったためです。

最初に開いたときは、次の3点を目視で確認してください。

1. 内面3パネルの中段で、**身長スケールの水平線が折り線をまたいで一直線につながっている**か（`.sz-gap` の位置と SVG の `y=108.5` が合っているか）
2. 内フラップ（外面いちばん左・97mm）で、下端の GIFT 3点がパネルからはみ出していないか
3. 内側左パネル上段の「カテゴリのチップ」が3行以上に折り返していないか（折り返すと下の性別ボックスが押し出されます）

いずれも詰まっている場合は、`.in` の `grid-template-rows`（現在 `70mm 64mm 1fr`）で段の高さを振り直すのがいちばん影響が小さい調整です。
